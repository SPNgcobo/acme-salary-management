# ACME Salary Management

Web application for the ACME HR Manager to manage salaries for 10,000
employees across multiple countries.

## Status
Work in progress — assessment submission for Incubyte.

## Structure
- `backend/` — Spring Boot 4.1.1 REST API + PostgreSQL + Flyway
- `frontend/` — Angular UI (in progress)
- `docs/` — requirements, architecture, design decisions, AI work log
- `scripts/` — seed data and utility scripts
